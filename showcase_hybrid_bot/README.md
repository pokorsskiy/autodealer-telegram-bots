# Гибридный бот

Бот объединяет быстрые действия обычного Telegram showcase и опубликованный
Web App-каталог. В чате доступны калькулятор, FAQ и ссылки; кнопка «Связаться»
ведёт напрямую к менеджеру. Каталог, его калькулятор и подробная форма заявки
открываются в Web App.

Команда `/site` показывает отдельную кнопку открытия Web App. В обычном меню
остаётся кнопка каталога, а отдельная кнопка «Сайт» не дублируется.

Команда `/admin` присылает кнопку общей с `showcase_webapp_bot` админки
только Telegram-аккаунтам из `ADMIN_TELEGRAM_IDS`; остальные видят главное
меню. Вход без пароля проверяет сервер витрины, поэтому токен этого бота
должен быть в `ADMIN_EXTRA_BOT_TOKENS` у `showcase_webapp_bot`, а сами ID — в
его `ADMIN_TELEGRAM_IDS`.

Заявки из Web App гибрид сохраняет у себя, отправляет менеджеру в Telegram и
передаёт копию в эту админку (`/api/bot/leads` на хосте из `WEB_APP_URL`),
подписав запрос своим токеном. Если админка недоступна, клиент этого не
заметит: ошибка только попадёт в журнал.

Telegram-калькулятор повторяет сценарий Web App: выбор известной стоимости или
ориентира, сумма, возраст, двигатель и итог с доставкой и расходами.

Скопируйте `.env.example` в `.env` и заполните как минимум `BOT_TOKEN`,
`YOUR_CHAT_ID`, `DEMO_MODE`, публичный HTTPS-адрес `WEB_APP_URL` и ссылку `MANAGER_URL`.
Остальные ссылки и параметры необязательны.

`DEMO_MODE` обязателен, без него бот не запустится: `1` — демо, данные из Web App
не сохраняются и никуда не пересылаются; `0` — рабочий бот заказчика.

`LEAD_NOTIFY_CONTACTS=0` — уведомление о заявке без имени и телефона клиента, с кнопкой
админки; контакты видны только в админке. Ставится вместе с тем же значением у сервера
витрины. По умолчанию `1` — полная заявка.

`TELEGRAM_API_URL` необязателен: адрес посредника к Bot API, если сервер стоит в России
и `api.telegram.org` с него недоступен.

Заявка из Web App принимается только с отметкой согласия на обработку персональных
данных; время согласия хранится в колонке `consent_at`. Страницы политики и согласия
отдаёт сервер витрины (`showcase_webapp_bot`, файл `legal.json`).

Для `WEB_APP_URL` можно использовать тот же опубликованный интерфейс и Flask-сервер,
что у `showcase_webapp_bot`: данные формы будут отправлены тому Telegram-боту,
из меню которого пользователь открыл Web App.

## Запуск и проверка

Бот запускается из своей папки:

```bash
cd showcase_hybrid_bot
python check_project.py
python -m unittest
python bot.py
```

## Обложка меню

`menu-cover.jpg` (1280×720): неоновый контур Lamborghini Urus между пузырями переписки и телефоном с каталогом — чат и Web App в одном боте.

Картинка отправляется фото с подписью при `/start`; после первой отправки Telegram возвращает `file_id`, его можно указать в `MENU_COVER_FILE_ID`, чтобы не загружать файл каждый раз.
