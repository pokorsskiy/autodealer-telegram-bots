# Telegram-бот с калькулятором

Демонстрационный бот для автомобильного бизнеса. Весь интерфейс работает в
Telegram: предварительный калькулятор, FAQ, переход к менеджеру, отзывы, общий
чат и ссылки на социальные сети.

## Пользовательский сценарий

1. `/start` открывает главное меню.
2. «Калькулятор» последовательно запрашивает стоимость автомобиля в рублях,
   возраст и объём двигателя в литрах. Для таможенной формулы стоимость
   автоматически пересчитывается в евро по настроенному курсу.
3. Бот показывает предварительную стоимость с разбивкой.
4. Пользователь переходит к менеджеру для точного расчёта.

Inline-навигация редактирует одно сообщение. Новые сообщения появляются только
при вводе пользователем данных и при сообщениях об ошибках ввода.

## Настройка

Скопируйте `.env.example` в `.env` и укажите:

- `BOT_TOKEN` — токен отдельного демонстрационного бота;
- `DEMO_MODE` — обязательно, без значения бот не запустится: `1` — демо, заявки никуда не отправляются и не сохраняются, вместо отправки показывается образец заявки с вымышленным клиентом; `0` — рабочий бот заказчика;
- `MANAGER_URL` — username или ссылка на менеджера: кнопка «Написать менеджеру» в главном меню, без ссылки её нет;
- ссылки на отзывы, общий чат и социальные сети.

Если ссылка не настроена, кнопки нет. Курс и расходы калькулятора заданы в `calculator.py`.

## Калькулятор

Таможенная пошлина рассчитывается по единым ставкам для автомобилей личного
пользования из приложения № 2 к Решению Совета ЕЭК от 20.12.2017 № 107:

<https://eec.eaeunion.org/upload/medialibrary/48d/754bnati3u804penijmb0h866e5g6cng/Prilozhenie-2_107.pdf>

Результат предварительный. Он не заменяет индивидуальную смету и может не
учитывать точный утилизационный сбор, льготы, хранение и другие расходы.

## Запуск и проверка

Бот запускается из своей папки:

```bash
cd showcase_telegram_bot
python check_project.py
python -m unittest
python bot.py
```

## Обложка меню

`menu-cover.jpg` (1280×720): неоновый контур Mercedes-AMG GT на тёмном фоне, иконки переписки, калькулятора и менеджера — то, что умеет бот в чате.

Картинка отправляется фото с подписью при `/start`; после первой отправки Telegram возвращает `file_id`, его можно указать в `MENU_COVER_FILE_ID`, чтобы не загружать файл каждый раз.
