# Бот-витрина

Навигатор по трём ботам-примерам: карточка каждого с описанием, видео и кнопкой запуска.
Данных не собирает и базы не имеет — самый простой бот проекта.

## Экраны

- Главное меню с обложкой.
- «Примеры ботов» — список и карточки. Карточка: что бот умеет, на чём держится, видео,
  кнопки «Открыть бота» и «Попробовать админку».
- «Как это сделано» — стек и устройство проекта.

## Настройка

Скопируйте `.env.example` в `.env`. Обязателен только `BOT_TOKEN`; ссылка, которой нет,
просто не даёт кнопки.

- `TELEGRAM_SHOWCASE_URL`, `WEBAPP_SHOWCASE_URL`, `HYBRID_SHOWCASE_URL` — боты-примеры;
- `ADMIN_DEMO_URL` — демо-админка Web App-бота, `https://<сайт>/admin/demo`;
- `REPO_URL` — репозиторий для кнопки «Исходный код»;
- `*_VIDEO_ID` — ролики в карточках, см. ниже.

## Запуск и проверка

```bash
cd showcase_bot
python check_project.py
python -m unittest
python bot.py
```

## Что здесь можно посмотреть

- `bot.py` — один обработчик callback-запросов на все экраны. Главное меню и карточки с видео —
  сообщения с медиа, а их нельзя превратить в текст через `edit_message_text`, поэтому
  `edit_screen` в таком случае удаляет сообщение и отправляет новое.
- `logger.py` — фильтр, который вырезает токен бота из сообщений и трассировок: библиотека
  кладёт в текст ошибки полный адрес запроса вместе с токеном.
- Обложка и видео отправляются по `file_id`, а не файлом: Telegram отдаёт их мгновенно.
  `file_id` у каждого бота свой, поэтому ролик присылают самой витрине, а она пишет
  идентификатор в лог: `Видео «подпись»: … file_id=…`.
